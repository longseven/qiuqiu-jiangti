# 角色设定 · 球球(数学闯关吉祥物)

> 单一事实来源 = [`mascot.py`](mascot.py)。改角色**只改这一个文件**,全系列视频自动统一。
> 设定图:[`mascot_sheet.png`](mascot_sheet.png) · 透明素材:`assets/mascot_<表情>.png`

## 身份
- **名字**:球球(想改的话改 `mascot.py` 里的 `NAME`)
- **设定**:圆滚滚的青绿色小球,陪你一起闯数学关;会滚、会做表情。

## 锁定配色(改 `mascot.py` 顶部常量)
| 用途 | 变量 | 色值 |
|---|---|---|
| 身体 | `BODY` | `#4ecdc4` |
| 描边/手脚 | `OUT` | `#2a9d96` |
| 腮红 | `CHEEK` | `#ff9aa2` |
| 眼睛/嘴 | `EYE` | `#11324a` |
| 汗滴 | `SWEAT` | `#6cc6ff` |
| 灯泡 | `BULB` | `#ffcf6e` |

## 比例(以头半径 `s` 为基准单位,等比缩放)
- 头:半径 `s` 的圆;脚两只在 `cy-1.02s`;手在 `±0.92s`。
- 眼:中心 `(±0.36s, +0.12s)`,白眼半径 `0.30s`,瞳孔 `0.15s`。
- 腮红:`(±0.52s, -0.20s)`,半径 `0.15s`;嘴:`cy-0.42s`。

## 14 种表情(`expr` 参数)
| expr | 中文 | 用在哪 |
|---|---|---|
| `happy` | 开心 | 默认/待机 |
| `panic` | 慌张 | 遇到难题、钩子(瞪眼+汗滴+挑眉) |
| `think` | 思考 | 推导中(眼睛上瞟) |
| `idea` | 灵光 | 想通/化简成功(头顶灯泡) |
| `cheer` | 欢呼 | 通关/得证(举手) |
| `wave` | 挥手 | 结尾引导 |
| `point` | 指向 | 讲解时指图/指公式(伸手) |
| `love` | 惊叹 | "哇太牛了"(星星眼) |
| `wink` | 俏皮 | 小技巧/小彩蛋(单眼眨) |
| `cool` | 自信 | "轻松拿下"(墨镜) |
| `cry` | 沮丧 | 做错/卡住(流泪) |
| `angry` | 燃 | BOSS 战/拼了(火苗+怒眉) |
| `dizzy` | 懵 | 被绕晕/条件吓人(漩涡眼) |
| `thumbsup` | 点赞 | "答对了/赞"(举手比赞) |

## 怎么用
**① 画进动画**(任意 matplotlib axes,坐标系需大致等比):
```python
from mascot import draw_mascot
draw_mascot(ax, cx=4.5, cy=2.4, s=0.95, expr="cheer", t=当前秒)
```
`t` 传当前时间会有轻微上下浮动 + 自动眨眼。`animate_fun.py` 已这样接入。

**② 当贴纸/封面素材**:直接用 `assets/mascot_<表情>.png`(透明背景 PNG,可拖进任何剪辑/PPT/封面)。
重新生成:`python mascot.py --sprites`;重出设定图:`python mascot.py --sheet`。

## 扩展(加新表情/姿势)
在 `mascot.py` 的 `draw_mascot` 里加一个 `expr` 分支,并把名字加进 `EXPRESSIONS`,设定图与素材会自动带上它。
